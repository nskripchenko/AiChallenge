# День 10. Управление контекстом: разные стратегии

## Что сделано

Реализованы 3 независимые стратегии управления контекстом с переключением через вкладки

## Стратегии

### 1. Sliding Window (Скользящее окно)

Самая простая стратегия — отправляем только последние N сообщений

**Как работает:**
- Сохраняются все сообщения, но к AI отправляются только последние `windowSize`
- Старые сообщения показываются в сворачиваемой секции
- Секция: `🪟 12 older messages (not sent to AI) ▼`
- При раскрытии — превью каждого сообщения

**Настройки:**
| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| Window Size | 10 | Количество последних сообщений для AI |

### 2. Sticky Facts (Липкие факты)

Автоматическое извлечение важных фактов через Haiku

**Как работает:**
- После каждого ответа Claude, Haiku анализирует обмен
- Извлекает ключевые факты: имена, предпочтения, технические детали
- Факты добавляются в system prompt как контекст
- Факты обновляются при появлении новой информации

**UI элементы:**
- **Facts Panel** в настройках показывает все извлечённые факты
- **Индикатор**: `extracting...` при работе Haiku
- **Бейдж**: `updated` после обновления фактов
- Формат фактов: `KEY: value`

**В логах:**
- Запросы на извлечение фактов помечены: `📌 FACTS`

### 3. Branching (Ветвление)

Создание альтернативных веток разговора (как git branches)

**Как работает:**
- Из любого сообщения можно создать новую ветку
- Каждая ветка — независимая история сообщений
- Можно переключаться между ветками
- Ветки можно удалять (кроме main)

**UI элементы:**
- **Branch selector** в заголовке чата: `🌿 main ▼`
- **Fork button** на каждом сообщении: `🌿 fork`
- **Диалог создания ветки**: ввод имени, выбор точки ветвления
- Удаление веток через `×` в dropdown меню

**Пример использования:**
1. Ведёте разговор в main ветке
2. На сообщении 5 нажимаете `fork`
3. Создаёте ветку "alternative-approach"
4. Продолжаете разговор в новом направлении
5. Можете переключиться обратно на main

## Визуальные индикаторы

### Sliding Window
- Жёлтый бейдж: `🪟 N older messages (not sent to AI)`
- Сворачиваемая секция с превью старых сообщений

### Sticky Facts
- Facts Panel в настройках
- Прогресс-бар при извлечении
- Зелёный бейдж `updated` после обновления

### Branching
- Branch selector в заголовке чата
- Fork button на каждом сообщении
- Dropdown со списком веток

## Запуск

```bash
export ANTHROPIC_API_KEY="sk-..."
./gradlew composeApp:run
```

Переключайтесь между стратегиями через вкладки в верхней части интерфейса.
