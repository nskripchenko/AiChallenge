## Quick Ask (Day 27)

**Quick Ask** - минималистичное desktop приложение для быстрых вопросов к локальной LLM.

### Запуск

```bash
# 1. Запустить Ollama (в отдельном терминале)
ollama serve

# 2. Запустить Quick Ask
./gradlew :composeApp:runQuickAsk
```

### Требования

- Ollama установлен и запущен
- Модель llama3.2 (или другая) загружена: `ollama pull llama3.2`

### Возможности

| Функция            | Описание                                    |
|--------------------|---------------------------------------------|
| **Минимальный UI** | Только поле ввода и область ответа          |
| **Dark Theme**     | Тёмная тема Material3                       |
| **Enter to Send**  | Отправка вопроса по Enter                   |
| **Loading State**  | Индикатор загрузки во время ответа          |
| **Error Handling** | Отображение ошибок (если Ollama недоступна) |

### Архитектура

## Оптимизация LLM (Day 29)

Настройка параметров локальной модели для RAG.

### Параметры по режимам

| Режим | Temperature | Max Tokens | Описание |
|-------|-------------|------------|----------|
| **Grounded** | 0.1 | 256 | Максимально детерминированный |
| **RAG** | 0.3 | 512 | Баланс точности и вариативности |
| **Plain** | 0.5 | 512 | Более креативный |
| **Memory** | 0.3 | 512 | Для диалогов |

### Общие настройки (Config.kt)

```kotlin
object LLM {
    const val TEMPERATURE = 0.3f    // Базовая температура
    const val MAX_TOKENS = 512      // Лимит ответа
    const val CONTEXT_SIZE = 4096   // Окно контекста
    const val TOP_P = 0.9f          // Top-p sampling
    const val REPEAT_PENALTY = 1.1f // Штраф за повторы
}
```

### Квантование

| Модель | Квантование | Размер | Качество |
|--------|-------------|--------|----------|
| llama3.2 | Q4_K_M | 2GB | Хорошее |
| llama3.1:8b | Q4_K_M | 4.9GB | Лучше |

Q4_K_M — оптимальный баланс размера и качества.

### Оптимизированные промпты

- **Grounded**: Строгий промпт без галлюцинаций
- **RAG**: Сжатый промпт для контекстных ответов
- **Plain**: Минимальный промпт для общих вопросов

## LLM как сетевой сервис (Day 30)

RAG Demo поддерживает подключение к Ollama по сети — для использования как приватный AI-сервис.

### Настройка сервера

```bash
# На сервере (Mac/Linux с Ollama)
OLLAMA_HOST=0.0.0.0:11434 ollama serve
```

### Запуск клиента

```bash
# На клиенте — указать IP сервера
OLLAMA_HOST=192.168.1.17:11434 ./gradlew :composeApp:run
```

### Конфигурация

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `OLLAMA_HOST` | Адрес Ollama сервера (host:port) | `localhost:11434` |

### Архитектура

```
┌─────────────────┐         ┌─────────────────┐
│   RAG Demo      │   HTTP  │  Ollama Server  │
│   (клиент)      │────────▶│  (192.168.x.x)  │
│                 │         │                 │
│ OLLAMA_HOST=... │         │ llama3.2        │
└─────────────────┘         └─────────────────┘
```

### UI индикация

В интерфейсе отображается адрес текущего сервера:
```
RAG Demo - Day 30
Server: http://192.168.1.17:11434
```

### Тестирование сетевого доступа

```bash
# 1. На сервере — запустить Ollama для сети
OLLAMA_HOST=0.0.0.0:11434 ollama serve

# 2. Проверить список моделей
curl http://<SERVER_IP>:11434/api/tags

# 3. Тест запроса
curl http://<SERVER_IP>:11434/api/generate \
  -d '{"model": "llama3.2", "prompt": "Hello", "stream": false}'

# 4. Тест чата (многоходовый диалог)
curl http://<SERVER_IP>:11434/api/chat -d '{
  "model": "llama3.2",
  "stream": false,
  "messages": [
    {"role": "user", "content": "Меня зовут Никита"},
    {"role": "assistant", "content": "Приятно познакомиться!"},
    {"role": "user", "content": "Как меня зовут?"}
  ]
}'
```

### Ограничения

| Параметр | Значение | Описание |
|----------|----------|----------|
| Context Window | 4096 tokens | Максимальный контекст |
| Max Tokens | 512 (настраивается) | Лимит ответа |
| Rate Limit | Нет (Ollama) | Ограничения на уровне ОС |
