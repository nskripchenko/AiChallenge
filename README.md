# День 9. Управление контекстом: сжатие истории

## Что сделано

Реализована автоматическая суммаризация старых сообщений для экономии токенов

## Как работает

1. **Порог сжатия**: когда `unsummarizedCount > keepRecent * 2`
2. **Rolling summarization**: новые сообщения добавляются к существующему summary
3. **Контекст для API**: `[summary message] + [recent messages]`
4. **UI показывает**: все сообщения, но старые помечены как суммаризованные

## Визуальные индикаторы

### В чате (ChatPanel)
- **Разделитель**: `📝 5 messages → summary ▼` — кликабельный, раскрывает полный текст summary
- **Индикатор сжатия**: анимированный прогресс-бар "Summarizing context..." при работе Haiku

### В настройках (Settings)
- **Context card**: сегментированный прогресс-бар
  - Серый = суммаризованные сообщения
  - Чёрный = недавние сообщения
  - Легенда: `■ N summarized  ■ M recent`
- **Tokens card**: использование токенов

### В логах (LogPanel)
- Суммаризационные запросы помечены: `📝 SUMMARIZE`
- Видна модель Haiku и параметры (temp 0.3, max 500)

## Настройки

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| Keep recent | 10 | Сколько последних сообщений хранить без сжатия |
| History limit | 1000 | Лимит токенов для истории |

## Персистентность

Состояние сохраняется в `~/.aichallenge/chat_history.json`:
```json
{
  "messages": [...],
  "summary": "Previous conversation discussed...",
  "summarizedCount": 5
}
```
