# День 8. Работа с токенами

## Что сделано

Реализован подсчёт токенов на всех уровнях:

| Метрика                              | Где отображается              |
|--------------------------------------|-------------------------------|
| Токены текущего ввода                | Под полем ввода (`~N tokens`) |
| Токены запроса (история + сообщение) | Под сообщением пользователя   |
| Токены ответа модели                 | Под сообщением Claude         |
| Общая статистика сессии              | Settings → Session card       |

## Стоимость

Каждое сообщение показывает:

- **User**: estimated input tokens + cost (история + сообщение)
- **Claude**: actual tokens + response time + cost

## Запуск

```bash
export ANTHROPIC_API_KEY="sk-..."
./gradlew composeApp:run
```
