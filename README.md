# День 11. Модель памяти AI-ассистента

## Что сделано

Реализована трёхуровневая модель памяти для AI-ассистента с персистентным хранением в JSON.

## Архитектура памяти

```
┌─────────────────────────────────────────────────────────────┐
│                      System Prompt                          │
│  ┌─────────────┐ ┌─────────────┐ ┌─────────────────────┐   │
│  │ Долговрем.  │ │   Рабочая   │ │   Пользовательский  │   │
│  │   память    │ │   память    │ │       промпт        │   │
│  └─────────────┘ └─────────────┘ └─────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                              +
┌─────────────────────────────────────────────────────────────┐
│                    Messages (история)                        │
│              Краткосрочная память (N сообщений)             │
└─────────────────────────────────────────────────────────────┘
```

## Три уровня памяти

### 1. Краткосрочная память (Short-term)

**Что это**: Последние N сообщений диалога

- Автоматически управляется
- Настраиваемый лимит сообщений
- Не сохраняется отдельно (это история чата)

### 2. Рабочая память (Working)

**Что это**: Данные текущей задачи

- Пользователь сам добавляет/удаляет элементы
- Пары "метка → содержимое"
- Сохраняется в `~/.aichallenge/working_memory.json`

**Примеры использования**:

- Текущая задача: "Рефакторинг AuthService"
- Требования: "REST API, JWT токены"
- Контекст файла: "Работаем с src/auth/service.ts"

### 3. Долговременная память (Long-term)

**Что это**: Постоянная информация о пользователе

Содержит:

- **Профиль**: имя, контекст, предпочтения
- **Решения**: архитектурные и технические решения
- **База знаний**: категоризированная информация

Сохраняется в `~/.aichallenge/long_term_memory.json`

## Как это работает

1. При старте приложения загружается сохранённая память
2. При каждом запросе к AI память собирается в system prompt
3. При изменении памяти она автоматически сохраняется в JSON

```kotlin
// Сборка контекста
val memoryContext = """
=== ПРОФИЛЬ ПОЛЬЗОВАТЕЛЯ ===
Имя: Алексей
Контекст: Backend разработчик

=== ВАЖНЫЕ РЕШЕНИЯ ===
• Архитектура: Clean Architecture
• База данных: PostgreSQL

=== РАБОЧАЯ ПАМЯТЬ ===
• Задача: Реализовать авторизацию
"""

// Отправка в API
system = memoryContext + userSystemPrompt
messages = recentMessages
```

## Файлы хранения

| Файл                                   | Содержимое            |
|----------------------------------------|-----------------------|
| `~/.aichallenge/working_memory.json`   | Рабочая память        |
| `~/.aichallenge/long_term_memory.json` | Долговременная память |
| `~/.aichallenge/chat_history.json`     | История диалога       |

## Запуск

```bash
export ANTHROPIC_API_KEY="sk-..."
./gradlew composeApp:run
```

## Ограничения

- Память не извлекается автоматически из диалога
- Пользователь сам решает что сохранять
- Большой объём памяти съедает токены контекста
