# Crypto Consultant

Desktop-приложение для анализа криптовалют с AI-ассистентом на базе Claude.
Just for fun.

## Возможности

- Анализ рынка криптовалют в реальном времени (CoinGecko API)
- Персонализированные рекомендации на основе профиля
- Расчёт точек входа, take-profit и stop-loss
- Трёхуровневая модель памяти
- Детерминированная стейт-машина для выполнения задач
- Инварианты — правила, которые AI не может нарушить

## Профиль пользователя

| Параметр | Описание                                         |
|----------|--------------------------------------------------|
| Deposit  | Сумма для инвестирования (USD/EUR/RUB)           |
| Target   | Целевая доходность (% за N дней)                 |
| Risk     | Консервативный / Умеренный / Агрессивный         |
| Horizon  | Внутри дня / Краткосрок / Среднесрок / Долгосрок |

## Модель памяти

```
~/.aichallenge/
├── chat_history.json      # История диалога
├── working_memory.json    # Заметки (рабочая память)
├── long_term_memory.json  # Профиль и настройки
└── invariants.json        # Инварианты
```

### Три уровня:

1. **Short-term** — последние N сообщений диалога
2. **Working** — заметки пользователя (Notes в UI)
3. **Long-term** — профиль, решения, знания

## Инварианты

Правила, которые AI **не может нарушить**. Имеют приоритет над любым запросом пользователя.

### Типы инвариантов

| Тип          | Описание                 | Пример                                |
|--------------|--------------------------|---------------------------------------|
| **MUST**     | Обязательное действие    | Всегда указывать stop-loss            |
| **MUST_NOT** | Запрещённое действие     | Не рекомендовать мем-коины            |
| **LIMIT**    | Числовое ограничение     | Максимум 30% депозита в одну позицию  |

### Дефолтные инварианты

| Инвариант       | Тип      | Описание                                       |
|-----------------|----------|------------------------------------------------|
| Лимит позиции   | LIMIT    | Максимум 30% депозита в одну криптовалюту      |
| Stop-loss       | MUST     | Всегда указывать stop-loss для каждой рекомендации |
| Мем-коины       | MUST_NOT | Не рекомендовать DOGE, SHIB, PEPE, FLOKI       |
| Leverage        | MUST_NOT | Не рекомендовать кредитное плечо и маржу       |
| Диверсификация  | MUST     | Минимум 2-3 актива в портфеле (опционально)    |

### Поведение при нарушении

Если запрос пользователя противоречит инварианту:

1. AI **немедленно отказывается** выполнять запрос
2. AI чётко называет какой инвариант нарушается
3. AI **НЕ** даёт рекомендацию, нарушающую правила
4. AI предлагает альтернативу в рамках правил

### Управление

Кнопка **Rules** в заголовке → диалог управления инвариантами:
- Включить/выключить отдельные инварианты
- Сбросить к дефолтным значениям

## Task State Machine

Детерминированный конечный автомат для структурированного выполнения задач.

### Когда активируется

Task State Machine активируется **только** при запросе структурированной задачи:

| Запрос                         | Task State Machine |
|--------------------------------|--------------------|
| `Что такое Bitcoin?`           | Не активируется    |
| `Порекомендуй что купить`      | Не активируется    |
| `Рекомендуй DOGE` (инвариант)  | Не активируется    |
| `Создай план инвестиций`       | Активируется       |
| `Составь план покупок`         | Активируется       |
| `Разработай стратегию`         | Активируется       |

**Ключевые слова:** `создай план`, `составь план`, `инвестиционный план`, `стратегию`, `пошаговый`

### Фазы

```
IDLE → PLANNING → EXECUTING → VALIDATING → COMPLETED
          ↑           ↑            ↑
          └───────────┴────────────┘
                 (можно вернуться)

      PAUSED ← (любая фаза кроме IDLE/COMPLETED)
```

| Фаза       | Описание                      | Артефакт          |
|------------|-------------------------------|-------------------|
| IDLE       | Ожидание задачи               | —                 |
| PLANNING   | Создание плана выполнения     | Plan              |
| EXECUTING  | Пошаговое выполнение плана    | StepExecution     |
| VALIDATING | Проверка результатов          | ValidationReport  |
| COMPLETED  | Задача завершена              | CompletionSummary |
| PAUSED     | Пауза с сохранением состояния | —                 |

### Управление задачей

| Кнопка                 | Действие                             |
|------------------------|--------------------------------------|
| **Approve Plan**       | Одобрить план → переход к выполнению |
| **Reject**             | Отклонить план → AI создаёт новый    |
| **Approve Step**       | Одобрить шаг → следующий шаг         |
| **Approve & Complete** | Завершить задачу                     |
| **Pause**              | Приостановить выполнение             |
| **Resume**             | Продолжить с места остановки         |
| **Cancel**             | Отменить задачу полностью            |

### Пример использования

1. Напишите: `Создай инвестиционный план на неделю`
2. AI создаёт план с шагами → появляется **Task Progress**
3. Нажмите **Approve Plan** → AI выполняет шаги
4. После выполнения → **Validating** → **Approve & Complete**

### Взаимодействие с инвариантами

- При создании плана AI проверяет его на соответствие инвариантам
- Если план нарушает инвариант, AI отказывается его создавать
- Инварианты имеют приоритет над любой фазой Task State Machine

### Принципы

1. **Детерминированные переходы** — переход только после approval
2. **Блокирующие состояния** — AI не может перепрыгнуть фазу
3. **Свой system prompt** на каждую фазу
4. **Пауза/Resume** на любом этапе с сохранением состояния

## Примеры запросов

**Простые вопросы (без Task Progress):**
```
Что такое стоп-лосс?
Какая сейчас цена Bitcoin?
Порекомендуй что купить
```

**Структурированные задачи (с Task Progress):**
```
Создай инвестиционный план на неделю
Составь план покупок на $500
Разработай стратегию для агрессивного профиля
```

**Тестирование инвариантов:**
```
Рекомендуй DOGE          → AI откажет (мем-коин)
Вложи всё в Bitcoin      → AI откажет (> 30%)
Как использовать плечо?  → AI откажет (leverage)
```
